## 编码器
### 编码器初始化
1. 工程使用增量式 AB 正交编码器：编码器输出 A、B 两路脉冲，STM32 通过两路信号的相位关系判断旋转方向，通过脉冲数量判断旋转角度。
2. 在 MX_TIM3_Init() 中配置一个定时器为编码器模式，给定两个引脚分别接收编码器 A、B 两相信号。计数范围为 0～4095。对应编码器分辨率为 4096 步/圈。
3. 定义一个编码器句柄结构体，用于存储编码器的计数、角度、转速等信息。编码器句柄里定义了：
   - `htim`：编码器定时器句柄，这决定了编码器绑定了哪个定时器
   - `spd_last_count`：上次测速时的编码器计数
   - `count`：当前编码器计数
   - `angle_m`：机械角度，rad
   - `angle_e`：电角度，rad
   - `angle_e_offset`：电角度零点偏置，rad
   - `speed`：机械转速，rpm
   - `speed_raw`：未滤波的差分转速，rpm
### 编码器校准
1. 上电清零：增量式编码器计数清零，软件将当前位置定义为机械角度 \(0^\circ\)。但转子的真实机械角度和电角度都是未知的，不能认为实际电角度也是 \(0^\circ\)。
2. 固定磁场对齐：通过 SVPWM 施加方向已知的固定定子磁场，使转子趋向一个已知的电角度位置。在我们的工程中，将该位置对应的电角度设为 \(0^\circ\)。
3. 采集编码器读数：转子对齐后，采集10次编码器角度并计算平均值，得到相对于上电零点的机械角度 \(y\)。此时我们仍不知道转子的绝对机械角度。
4. 计算电角度偏置：根据极对数 \(p\)，编码器未经校准计算出的电角度为 \(py\)，而对齐位置对应的电角度为 \(0^\circ\)，因此：
\[
\boxed{\theta_{offset}=\operatorname{mod}(-py,360^\circ)}
\]

1. 实时电角度计算：校准完成后，编码器持续测量相对机械角度 \(\theta_m\)，通过以下公式计算电角度：
\[
\boxed{\theta_e=\operatorname{mod}(p\theta_m+\theta_{offset},360^\circ)}
\]

1. 用于 FOC 控制：将得到的电角度用于 Park 变换和逆 Park 变换，实现电流解耦控制和 SVPWM 驱动。

假设编码器的 Z 相对应实际机械角度 30°，那么启动流程可以设计成：
1. 上电初始化：TIM3 开始读取 A、B 相，暂时不知道绝对机械位置。
2. 电角度校准：按照当前 ZqFOC 的方法进行固定磁场对齐，保证 FOC 能正常驱动电机。
3. 寻找 Z 相：让电机低速旋转，直到检测到 Z 相脉冲。
4. 建立机械零点：记录此时编码器计数，并将该位置定义为机械角度 0°。
5. 正常位置控制：以后发送 A90，就让转子转到 Z 相参考位置正向 90° 的位置。

## 电流环
电流环接收一个电流指令值，并根据实际采样到的三相电流值进行 PID 控制，输出控制信号给 SVPWM 模块。
### 初始化
1. 绑定电流环的电角度来源，确保电流环能够获取到准确的电角度信息。
2. 绑定电流环的电流反馈来源，确保电流环能够及时获取到三相电流的采样值。
3. 绑定电流环的 SVPWM 输出，确保电流环能够控制电机的驱动信号。
4. 初始化参考值iq和id，初始化反馈值和输出
5. 初始化电流环的 PID 控制器，包括比例增益、积分增益和微分增益。
### 设置参考值
给定一个电流环对象，设置其参考值 iq 和 id，电流环会根据这些参考值进行控制。
### 更新电流环
首先，TIM1 CH4 按固定时序触发 ADC1、ADC2 的注入组进行电流采样。ADC1 注入转换完成后进入回调函数，当电机处于 RUNNING 状态时，调用 FOC_LOOP_CUR_Update() 执行电流环。
该函数接收电流环对象 loop_cur 和母线电压 v_bus，执行以下操作：
1. 创建 Clarke、Park 和逆 Park 变换的局部结果变量。
2. 调用 FOC_CURRENT_Update()，读取 ADC 转换值，扣除零电流偏置，计算 A、B 相实际电流，并重构 C 相电流，更新 loop_cur->current 指向的电流采样对象。
3. 调用 FOC_ENCODER_UpdateAngle()，更新 loop_cur->encoder 指向的编码器对象中的机械角度和电角度。
4. 通过 Clarke 变换，将三相电流 Ia、Ib、Ic 转换为两相静止坐标系电流 Iα、Iβ，保存至 loop_cur->i_alpha 和 loop_cur->i_beta。
5. 通过 Park 变换，结合当前电角度，将 Iα、Iβ 转换为旋转坐标系下的 Id、Iq，保存至 loop_cur->i_d 和 loop_cur->i_q。
6. 调用两个 PI 控制器，分别根据 Id、Iq 的参考值与反馈值计算电压指令 Vd、Vq，保存至 loop_cur->v_d 和 loop_cur->v_q。
7. 根据母线电压计算允许的最大电压矢量幅值，对 Vd、Vq 进行等比例限幅，避免超出逆变器的电压输出能力。
8. 通过逆 Park 变换，结合当前电角度，将 Vd、Vq 转换为静止坐标系电压 Vα、Vβ，保存至 loop_cur->v_alpha 和 loop_cur->v_beta。
9. 调用 FOC_SVPWM_Update()，根据 Vα、Vβ 和母线电压计算三相 PWM 占空比，并更新 TIM1 的比较寄存器，实现电机三相电压调节。
## 速度环
1. 初始化速度环，包括绑定编码器来源、输出给的电流环对象，以及初始化速度环的 PID 控制器。
2. TIM6定时器中断触发FOC_LOOP_SPD_Update()
3. 调用FOC_ENCODER_UpdateSpeed获取速度
4. 调用速度环的 PI 控制算法，根据实际速度与参考速度的偏差计算控制输出。
5. 设置速度环的控制输出给电流环对象，实现速度控制。
## 结构体的定义
最大的是定义一个foc_motor控制系统的结构体，其中包含了编码器结构体,电流采样结构体，电流环结构体，速度环结构体，位置环结构体，母线电压采集结构体，以及 SVPWM 输出结构体。这就相当于整个 FOC 控制系统的各个部分。
其中每个结构体又有各自的成员变量，用于存储该部分的数据和状态。例如，编码器结构体包含机械角度、电角度、编码器计数等成员；电流采样结构体包含三相电流采样值、偏置等成员；电流环结构体包含参考值、反馈值、控制输出等成员；速度环结构体包含参考速度、实际速度、控制输出等成员；位置环结构体包含参考位置、实际位置、控制输出等成员；母线电压采集结构体包含母线电压值等成员；SVPWM 输出结构体包含三相 PWM 占空比等成员。

整个foc控制系统，是由foc_manager文件进行最表层的应用函数编写，这些应用函数面向的是整个 FOC 控制系统的各个部分，通过调用这些应用函数，可以实现对电机的精确控制。
