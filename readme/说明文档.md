## PWSM建模
### 电压方程
1. dq坐标系下的电压方程：
\[
\boxed{
\begin{aligned}
u_d&=R_si_d+L_s\frac{di_d}{dt}-\omega_eL_si_q\\
u_q&=R_si_q+L_s\frac{di_q}{dt}+\omega_e(L_si_d+\psi_f)
\end{aligned}
}
\]
利用反park变换
反 Park 变换公式为：
\[
\boxed{
\begin{bmatrix}
u_\alpha\\
u_\beta
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta_e&-\sin\theta_e\\
\sin\theta_e&\cos\theta_e
\end{bmatrix}
\begin{bmatrix}
u_d\\
u_q
\end{bmatrix}
}
\]
展开就是：
\[
\begin{cases}
u_\alpha=u_d\cos\theta_e-u_q\sin\theta_e\\
u_\beta=u_d\sin\theta_e+u_q\cos\theta_e
\end{cases}
\]
三、代入电压方程并整理
这里最关键的是，电角度 \(\theta_e\) 随时间变化：
\[
\frac{d\theta_e}{dt}=\omega_e
\]

因此对电流进行求导时，例如：
\[
\begin{aligned}
\frac{di_\alpha}{dt}
={}&\frac{di_d}{dt}\cos\theta_e
-\frac{di_q}{dt}\sin\theta_e\\
&-\omega_e i_d\sin\theta_e
-\omega_e i_q\cos\theta_e
\end{aligned}
\]

可以发现，这里自然出现了与 \(\omega_e\) 有关的项。
将 dq 电压方程代入反 Park 变换，再利用上面的电流导数关系整理，最终得到：
\[
\boxed{
\begin{aligned}
u_\alpha&=R_si_\alpha+L_s\frac{di_\alpha}{dt}-\omega_e\psi_f\sin\theta_e\\
u_\beta&=R_si_\beta+L_s\frac{di_\beta}{dt}+\omega_e\psi_f\cos\theta_e
\end{aligned}
}
\]

定义反电动势：
\[
\boxed{
\begin{aligned}
e_\alpha&=-\omega_e\psi_f\sin\theta_e\\
e_\beta&=\omega_e\psi_f\cos\theta_e
\end{aligned}
}
\]

便得到我们熟悉的 αβ 电压模型：
\[
\boxed{
\begin{aligned}
u_\alpha&=R_si_\alpha+L_s\frac{di_\alpha}{dt}+e_\alpha\\
u_\beta&=R_si_\beta+L_s\frac{di_\beta}{dt}+e_\beta
\end{aligned}
}
\]
### 转速转矩公式
转速和转矩同样可以在 dq 坐标系与 αβ 坐标系下表示。仍以表贴式 PMSM 为例。

### 1. 转矩公式

1. dq 坐标系
对于表贴式 PMSM：
\[
\boxed{T_e=\frac32p\psi_f i_q}
\]

1. αβ 坐标系
\[
\boxed{T_e=\frac32p(\psi_\alpha i_\beta-\psi_\beta i_\alpha)}
\]

其中，转子永磁体在 αβ 坐标系中的磁链分量为：
\[
\begin{cases}
\psi_{f\alpha}=\psi_f\cos\theta_e\\
\psi_{f\beta}=\psi_f\sin\theta_e
\end{cases}
\]

对于表贴式 PMSM，定子电感在两轴上相同，定子电流自身的磁链项在转矩表达式中相互抵消，因此：
\[
\boxed{T_e=\frac32p\psi_f(i_\beta\cos\theta_e-i_\alpha\sin\theta_e)}
\]

因为 Park 变换满足：
\[
i_q=-i_\alpha\sin\theta_e+i_\beta\cos\theta_e
\]

代入后得到：
\[
\boxed{T_e=\frac32p\psi_f i_q}
\]

所以两种转矩公式完全等价。

### 2. 转速公式

转速属于机械运动量，不因 dq 或 αβ 坐标变换而改变。

电角速度：

\[ \boxed{\omega_e=\frac{d\theta_e}{dt}} \]

机械角速度：

\[ \boxed{\omega_m=\frac{\omega_e}{p}} \]

机械转速（RPM）：

\[ \boxed{n=\frac{60\omega_e}{2\pi p}} \]

此外，电机转速由机械运动方程决定：

\[ \boxed{J\frac{d\omega_m}{dt}=T_e-T_L-B\omega_m} \]

随着转速增加：
\[
\omega_e\uparrow\ \Rightarrow E\uparrow\ \Rightarrow i_q\text{调节能力受限}\ \Rightarrow T_e\text{受限}
\]

根据机械运动方程：
\[
\boxed{J\frac{d\omega_m}{dt}=T_e-T_L-B\omega_m}
\]

- 如果电磁转矩仍然大于负载转矩与摩擦转矩之和，电机仍能加速，只是加速能力受到限制。
- 如果电磁转矩等于负载转矩与摩擦转矩之和，加速度为零，转速保持不变。
- 如果电磁转矩小于负载转矩与摩擦转矩之和，电机就会减速。
## FOC控制
设定一个速度，PI控制器根据速度误差计算产生输出的iq*，然后送给电流PI控制器，电流PI控制器接收一个反馈的iq，这个反馈的iq是通过从电机上采集的三相电流经过Clarke park变换回来的iq，然后电流PI控制器计算输出出一个电压的Uq，因为三相逆变电桥需要的是开关关断的规则，所以先将这个Uq和Ud经过反park变换得到Uα和Uβ，然后将Uα和Uβ合成为Uref，Uref的幅值为sqrt(Uα^2+Uβ^2)，角度为atan2(Uβ,Uα)，然后我们就能在360度中唯一确定此次电流环所计算产生的目标电压矢量的大小和方向，根据这个大小和方向判断扇区，三相逆变电桥一共有3个桥臂，8种状态，6种有效状态，2种无效状态。将6种有效状态分为6个扇区，每个扇区对应60度，Uref的角度落在哪个扇区，就选择该扇区相邻两个基本矢量进行合成。比如Uref的角度落在第1扇区，那么就选择V1和V2两个基本矢量进行合成，这两个基本矢量的幅值都是Udc，他们两个可以合成0到60度内幅值为Udc/sqrt(3)的，任意角度的电压矢量。而无效状态用来调节幅值，加入0序越多，合成电压矢量越小。通过对应公式我们可以算出每个基本矢量的作用时间，然后通过这个作用时间计算出每一个开关管的作用时间（举例说明）。然后我们通过中心对称7段式来分配每个开关管的状态。比如第一相的开关管我们需要他最早导通，最晚关闭，那么我们就需要这一相的CCR设置的最小。
或者我们也可以使用minmax法来合成目标电压矢量，minmax法需要在获取到Uα和Uβ后，再经过反clarke变换得到目标三相电压的矢量。这说明我们本次电流环计算结果需要三相电压在本次电流环的时间周期内的平均电压为xxx，然后我们可以通过获取三相目标电压中的最大值和最小值，然后做一个零序注入，获取到修正后的三相电压目标值。接下来我们就是要让三项逆变桥工作，在本次电流环的时间周期内产生平均电压为目标值的电压，我们只需要分别对三相PWM设置占空比CCR1，CCR2，CCR3就可以了。

## 3. SMO 如何利用这些公式？

SMO 获得反电动势：

\[ \hat e\_\alpha,\hat e\_\beta \]

在已知正转方向且完成必要的滤波相位补偿后：

\[ \boxed{\hat\theta_e=\operatorname{atan2}(-\hat e\_\alpha,\hat e\_\beta)} \]

再利用 PLL 得到：

\[ \boxed{\hat\omega_e=\frac{d\hat\theta_e}{dt}} \]

最后转换成机械转速。

总结：

- 转矩：既可以用 dq 坐标系中的 \\(i_q\\) 计算，也可以用 αβ 坐标系中的磁链和电流计算。
- 转速：由电角度的变化率计算，与使用哪种坐标系无关。
- SMO：估算反电动势，进而得到电角度与转速，供 FOC 控制器使用。
## PWM

### 1. PWM 的基本原理

**PWM（Pulse Width Modulation，脉冲宽度调制）**：通过改变开关器件在固定周期内的导通时间，调节输出平均电压。

基本概念：

- **PWM 频率**：每秒重复多少个 PWM 周期。
- **占空比**：一个周期内高电平持续时间占总周期的比例。
- **载波**：用于产生 PWM 的周期性比较信号，中心对齐 PWM 可理解为使用三角载波。
- **调制波**：决定 PWM 占空比的参考信号。

占空比公式：

\[
\boxed{
D=\frac{T_{\mathrm{on}}}{T_{\mathrm{PWM}}}
}
\]

其中：

- \(T_{\mathrm{on}}\)：高电平持续时间。
- \(T_{\mathrm{PWM}}\)：PWM 周期。
- \(D\)：占空比，取值为 0～1。

对于理想半桥，其桥臂输出相对于直流母线负端的平均电压为：

\[
\boxed{
U_{\mathrm{avg}}=D\cdot U_{dc}
}
\]

其中 \(U_{dc}\) 为直流母线电压。

### 2. 中心对齐 PWM

ZqFOC 使用 STM32G431 的 TIM1 产生中心对齐 PWM。

### 2.1 工作原理

定时器计数器按照以下方式运行：

\[
0\rightarrow ARR\rightarrow0
\]

主要寄存器：

- **CNT**：当前计数器数值。
- **ARR**：自动重装寄存器，决定计数范围及 PWM 周期。
- **CCR**：捕获比较寄存器，决定 PWM 占空比。
- **PSC**：预分频器，决定定时器计数速度。

对于 PWM Mode 1、高电平有效的配置，非边界比较值下：

\[
CNT<CCR\Rightarrow\text{输出高电平}
\]

\[
CNT>CCR\Rightarrow\text{输出低电平}
\]

由于 CNT 周期性地向上和向下计数，因此 PWM 脉冲关于计数器谷底对称。

### 2.2 占空比计算

\[
\boxed{
D\approx\frac{CCR}{ARR}
}
\]

例如：

\[
ARR=5312,\qquad CCR=2656
\]

那么：

\[
D=\frac{2656}{5312}=50\%
\]

**结论：改变 CCR 只改变 PWM 占空比，不改变 PWM 频率。**

### 2.3 PWM 频率计算

中心对齐模式下：

\[
\boxed{
f_{\mathrm{PWM}}\approx
\frac{f_{\mathrm{TIM}}}{2(PSC+1)(ARR+1)}
}
\]

其中：

- \(f_{\mathrm{TIM}}\)：定时器时钟频率。
- \(PSC\)：预分频值。
- \(ARR\)：自动重装值。

对于 ZqFOC：

\[
f_{\mathrm{TIM}}=170\,\mathrm{MHz}
\]

\[
PSC=0,\qquad ARR=5312
\]

得到：

\[
f_{\mathrm{PWM}}\approx
\frac{170\times10^6}{2\times5313}
\approx16000\,\mathrm{Hz}
\]

因此：

\[
\boxed{
T_{\mathrm{PWM}}\approx62.5\,\mu s
}
\]

注：对于中心对齐计数，严格计算时计数周期与 \(2ARR\) 对应，上述使用 \(ARR+1\) 的表达式是常用近似。当前配置下两者差别极小。

每相使用一对互补 PWM 控制上下桥臂 MOSFET。

### 3.2 死区时间

死区时间（Dead Time）是指上下桥臂 MOSFET 切换时，插入一段两者均不导通的时间。

**作用：防止上下 MOSFET 同时导通，造成直流母线短路。**

ZqFOC 中：

```c
sBreakDeadTimeConfig.DeadTime = 149;
```

该数值是 STM32 定时器的死区编码值，并不是直接表示 149 ns。

按照当前定时器时钟及死区编码规则，死区时间约为 1 μs。

### 4. MOSFET 开关频率与 CCR 的关系

MOSFET 的开关节奏由 PWM 频率决定，而 CCR 决定每个周期内导通与关断时间的比例。

ZqFOC 的 PWM 频率为 16 kHz：

\[
T_{\mathrm{PWM}}=62.5\,\mu s
\]

不同占空比对应：

| 占空比 | 导通时间 | 关断时间 |
|---|---|---|
| 25% | 15.625 μs | 46.875 μs |
| 50% | 31.25 μs | 31.25 μs |
| 75% | 46.875 μs | 15.625 μs |

对于正常的 PWM 波形：

- 每秒约 16000 个 PWM 周期。
- 每周期通常包含一次导通和一次关断。
- 因此每秒约有 16000 个上升沿和 16000 个下降沿。

当占空比为 0% 或 100% 时，输出可能持续处于同一状态，不再产生周期性开关边沿。

**结论：CCR 改变的是每个 PWM 周期的脉冲宽度，而不是 PWM 周期本身。**

### 5. SVPWM 与 PWM 的关系

FOC 电流环中的 PI 控制器输出：

\[
u_d,\qquad u_q
\]

经过反 Park 变换：

\[
(u_d,u_q)
\xrightarrow{\text{反Park}}
(u_\alpha,u_\beta)
\]

SVPWM 将两相静止坐标系电压转换成三相占空比。

ZqFOC 使用的是**最大最小值零序注入法**。

### 5.1 三相电压计算

\[
\begin{aligned}
u_u&=u_\alpha\\
u_v&=-\frac12u_\alpha+\frac{\sqrt3}{2}u_\beta\\
u_w&=-\frac12u_\alpha-\frac{\sqrt3}{2}u_\beta
\end{aligned}
\]

### 5.2 零序电压注入

首先计算三相电压的最大值与最小值：

\[
u_{\max}=\max(u_u,u_v,u_w)
\]

\[
u_{\min}=\min(u_u,u_v,u_w)
\]

零序偏置：

\[
\boxed{
u_0=-\frac{u_{\max}+u_{\min}}{2}
}
\]

### 5.3 占空比计算

\[
\boxed{
\begin{aligned}
D_u&=0.5+\frac{u_u+u_0}{U_{dc}}\\
D_v&=0.5+\frac{u_v+u_0}{U_{dc}}\\
D_w&=0.5+\frac{u_w+u_0}{U_{dc}}
\end{aligned}
}
\]

随后计算比较寄存器：

\[
\boxed{
CCR_x=D_x\cdot ARR
}
\]

程序通过修改 CCR1、CCR2、CCR3，改变三相 PWM 占空比。

### 5.4 完整控制流程

\[
\boxed{
u_d,u_q
\xrightarrow{\text{反Park}}
u_\alpha,u_\beta
\xrightarrow{\text{SVPWM}}
D_u,D_v,D_w
\xrightarrow{\text{TIM1}}
\text{三相互补PWM}
}
\]

### 6. PWM 与 ADC 电流采样同步

ZqFOC 使用 TIM1_CH4 作为 ADC 注入转换的触发源。

控制流程：

1. TIM1 产生 16 kHz 中心对齐 PWM。
2. TIM1_CH4 在指定计数位置产生比较事件。
3. ADC1 和 ADC2 被 TIM1_CH4 触发，采集电机相电流。
4. ADC1 注入转换完成后进入中断回调。
5. 中断中执行 FOC 电流控制算法。
6. 重新计算 SVPWM，并更新 CCR1～CCR3。

主要代码：

```c
void HAL_ADCEx_InjectedConvCpltCallback(
    ADC_HandleTypeDef *hadc)
{
    if(hadc == &hadc1)
    {
        if(foc_motor.motor_state != FOC_STATE_RUNNING)
            return;

        FOC_LOOP_CUR_Update(
            &foc_motor.loop_cur,
            foc_motor.bus_voltage.voltage);
    }
}
```

**核心目的：使电流采样时刻与 PWM 开关时序同步，减少开关噪声对采样的影响。**

### 7.1 电机电频率

电频率与机械转速的关系：

\[
\boxed{
f_e=\frac{pn}{60}
}
\]

其中：

- \(p\)：电机极对数。
- \(n\)：机械转速，RPM。
- \(f_e\)：电频率，Hz。

例如，7 对极电机转速为 1000 RPM：

\[
f_e=\frac{7\times1000}{60}
\approx116.67\,\mathrm{Hz}
\]

说明：

- PWM 以 16 kHz 的频率开关。
- 电机定子磁场以约 116.67 Hz 的电频率旋转。
- 电流环以 16 kHz 的频率计算控制输出。
- 三者不是同一个概念。

## 8. 核心总结

| 概念 | 核心作用 |
|---|---|
| PSC | 决定定时器计数时钟的分频 |
| ARR | 决定 PWM 计数周期 |
| CNT | 定时器当前计数值 |
| CCR | 决定 PWM 占空比 |
| 载波 | 提供周期性的 PWM 比较基准 |
| SVPWM | 根据目标电压计算三相占空比 |
| 互补 PWM | 控制三相逆变桥的上下 MOSFET |
| 死区时间 | 防止同一桥臂上下管直通 |
| TIM1_CH4 | 同步触发 ADC 电流采样 |
| PWM 频率 | 决定 MOSFET 开关节奏 |
| 电频率 | 决定电机旋转磁场的转速 |

**最终记忆：**

1. **PSC + ARR 决定 PWM 频率。**
2. **CCR 决定 PWM 占空比。**
3. **SVPWM 负责计算三相占空比。**
4. **TIM1 负责将占空比转换成实际 PWM 信号。**
5. **死区时间负责避免桥臂直通。**
6. **CH4 负责同步触发 ADC 电流采样。**
7. **PWM 频率与电机电频率不同。**

## Clarke/Park变换

### 1. Clarke 变换（三相 → 两相静止坐标系）

作用：将三相静止坐标系 abc 中的电流转换为两相静止坐标系 αβ 中的电流。

采用等幅值变换，且满足三相电流之和为零：

\[
\boxed{
\begin{aligned}
i_\alpha &= i_a\\
i_\beta &= \frac{i_a+2i_b}{\sqrt{3}}
\end{aligned}
}
\]

其中：
- \(i_a,i_b,i_c\)：三相电流。
- \(i_\alpha,i_\beta\)：两相正交电流分量。

**物理意义：** 将三相合成电流矢量表示为静止 αβ 坐标系中的两个分量。

### 2. Park 变换（两相静止 → 两相旋转坐标系）

作用：将 αβ 坐标系中的电流转换为跟随转子磁场旋转的 dq 坐标系中的电流。

\[
\boxed{
\begin{aligned}
i_d &= i_\alpha\cos\theta_e+i_\beta\sin\theta_e\\
i_q &=-i_\alpha\sin\theta_e+i_\beta\cos\theta_e
\end{aligned}
}
\]

其中：
- \(\theta_e\)：转子电角度。
- \(i_d\)：d 轴电流，主要影响磁链。
- \(i_q\)：q 轴电流，主要控制电磁转矩。

**物理意义：** 将静止坐标系中的交流电流转换到随转子旋转的坐标系中，使稳态电流表现为近似直流量，方便 PI 控制。

### 3. 两种变换的区别

| 比较项目 | Clarke 变换 | Park 变换 |
|---|---|---|
| 输入 | abc 三相电流 | αβ 两相电流 |
| 输出 | αβ 两相电流 | dq 两相电流 |
| 坐标系 | 三相静止 → 两相静止 | 两相静止 → 两相旋转 |
| 是否需要电角度 | 不需要 | 需要 |
| 核心目的 | 简化三相电流表达 | 实现磁链与转矩解耦控制 |

完整 FOC 电流反馈流程：

\[
\boxed{
i_{abc}
\xrightarrow{\text{Clarke}}
i_{\alpha\beta}
\xrightarrow{\text{Park}}
i_{dq}
\xrightarrow{\text{电流 PI}}
u_{dq}
}
\]

随后经过反 Park 变换和 SVPWM，产生三相 PWM 占空比。
### 等幅值和等功率变换
#### 1. 等幅值变换

完整公式：

\[
\boxed{
\begin{bmatrix}
i_\alpha\\
i_\beta
\end{bmatrix}
=
\frac{2}{3}
\begin{bmatrix}
1 & -\frac12 & -\frac12\\
0 & \frac{\sqrt3}{2} & -\frac{\sqrt3}{2}
\end{bmatrix}
\begin{bmatrix}
i_a\\
i_b\\
i_c
\end{bmatrix}
}
\]

展开：

\[
\begin{cases}
i_\alpha=\frac23(i_a-\frac12i_b-\frac12i_c)\\
i_\beta=\frac{1}{\sqrt3}(i_b-i_c)
\end{cases}
\]

对于三相对称、无零序电流的系统：

\[
i_a+i_b+i_c=0
\]

因此：

\[
i_c=-i_a-i_b
\]

代入化简：

\[
\boxed{
\begin{aligned}
i_\alpha &= i_a\\
i_\beta &= \frac{i_a+2i_b}{\sqrt3}
\end{aligned}
}
\]

**结论：** 之前给出的简化公式与完整矩阵公式完全等价，前提是三相电流之和为零。

#### 2. 等功率变换

\[
\boxed{
\begin{bmatrix}
i_\alpha\\
i_\beta
\end{bmatrix}
=
\sqrt{\frac23}
\begin{bmatrix}
1 & -\frac12 & -\frac12\\
0 & \frac{\sqrt3}{2} & -\frac{\sqrt3}{2}
\end{bmatrix}
\begin{bmatrix}
i_a\\
i_b\\
i_c
\end{bmatrix}
}
\]

与等幅值变换相比，主要区别是前面的系数：

- 等幅值：\(2/3\)
- 等功率：\(\sqrt{2/3}\)

### 二、Park 变换的两种形式

需要注意：

**如果输入已经是采用对应归一化方式得到的 αβ 分量，那么等幅值和等功率 Park 变换使用相同的旋转矩阵。**

#### 1. 等幅值 Park 变换

\[
\boxed{
\begin{bmatrix}
i_d\\
i_q
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta_e & \sin\theta_e\\
-\sin\theta_e & \cos\theta_e
\end{bmatrix}
\begin{bmatrix}
i_\alpha\\
i_\beta
\end{bmatrix}
}
\]

#### 2. 等功率 Park 变换

\[
\boxed{
\begin{bmatrix}
i_d\\
i_q
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta_e & \sin\theta_e\\
-\sin\theta_e & \cos\theta_e
\end{bmatrix}
\begin{bmatrix}
i_\alpha\\
i_\beta
\end{bmatrix}
}
\]

## 三、两种变换的核心区别

| 比较项目 | 等幅值变换 | 等功率变换 |
|---|---|---|
| Clarke 系数 | \(2/3\) | \(\sqrt{2/3}\) |
| Park 旋转矩阵 | 相同 | 相同 |
| 相电流峰值为 10 A | dq 电流矢量幅值为 10 A | dq 电流矢量幅值约 12.25 A |
| 瞬时功率公式（无零序） | \(P=\frac32(u_di_d+u_qi_q)\) | \(P=u_di_d+u_qi_q\) |
| FOC 应用 | 常见 | 也可使用 |

## 四、总结

**等幅值和等功率不是两套不同的 FOC 算法，而是同一物理量采用了不同的坐标归一化方式。**

- 等幅值变换：保持三相正弦量峰值与两相矢量幅值一致。
- 等功率变换：保持坐标变换前后的瞬时功率一致。
- Park 旋转矩阵：两种归一化方式下相同。
- 实际应用：必须保证 Clarke、Park、反变换、电机模型和转矩公式采用一致的归一化定义。

对于现有的 Simulink FOC 模型，建议继续使用**等幅值 Clarke + Park 变换**，并确保所有相关模块使用相同的定义。



## 电流采样原理
我们的 ZqFOC 工程采用双电阻电流采样方案，通过采样电阻将电流信号转换为电压信号，再经过运算放大器放大，由 STM32 的 ADC 进行模数转换，得到数字采样值。
具体流程如下：
1. 采样电阻：利用欧姆定律 \(U=IR\)，将相电流转换为采样电阻两端的微小电压。
2. 运放放大：通过运算放大器将微小电压放大，便于ADC采集。
3. ADC转换：通过TIM1的CH4触发ADC1和ADC2注入组采样，获取A、B两相电流对应的ADC数值。
4. 电流换算：减去上电校准得到的ADC零偏，再根据采样电阻和放大倍数换算实际相电流。
5. 三相重构：根据 \(I_a+I_b+I_c=0\)，计算得到C相电流，最后进行Clarke和Park变换，得到Id、Iq作为电流环反馈。
电流换算公式
\[
\boxed{I=\frac{\Delta ADC\times3.3}{4095\times0.003\times10}}
\]

其中：
- 3.3V：ADC参考电压。
- 4095：12位ADC最大计数值。
- 0.003Ω：采样电阻。
- 10：运放增益。
- \(\Delta ADC\)：采样值与零偏的差值。
在我们的实际代码中，采用 零偏 − 采样值 的顺序，以匹配硬件电流反馈极性。
面试关键点：采样电阻将电流转换成电压，运放负责放大，ADC负责数字化，经过零偏补偿和比例换算得到电流反馈，最终用于FOC电流闭环控制。

## 电机配套
### 减速机
 减速机是一种通过齿轮等机械传动机构，降低输出转速、增大输出转矩的装置。
例如：
- 电机原本转速：3000 RPM
- 电机原本转矩：1 N·m
- 安装一个减速比为 10:1 的减速机
忽略损耗后：
\[
\boxed{n_{\mathrm{out}}=\frac{3000}{10}=300\ \mathrm{RPM}}
\]

\[
\boxed{T_{\mathrm{out}}=1\times10=10\ \mathrm{N\cdot m}}
\]

实际转矩还要乘上传动效率。
常见减速机包括行星减速器、谐波减速器、蜗轮蜗杆减速器、摆线针轮减速器等。
#### 为什么减速器能增大转矩？
核心原因是机械能守恒（考虑损耗时为功率平衡）。
机械功率公式：
\[
\boxed{P=T\omega}
\]

理想情况下，减速器输入功率等于输出功率：
\[
T_{\mathrm{in}}\omega_{\mathrm{in}}
=T_{\mathrm{out}}\omega_{\mathrm{out}}
\]

因此：
\[
\boxed{T_{\mathrm{out}}=\eta iT_{\mathrm{in}}}
\]

其中：
- \(i\)：减速比
- \(\eta\)：传动效率
- \(T_{\mathrm{in}}\)：输入转矩
- \(T_{\mathrm{out}}\)：输出转矩
例如，10:1 的减速器，效率为 90%：
\[
T_{\mathrm{out}}=1\times10\times0.9=9\ \mathrm{N\cdot m}
\]

本质：牺牲旋转速度，换取更大的转矩，并没有凭空增加功率。
#### 行星减速器
行星减速器是减速机的一种，通过太阳轮、行星轮和齿圈之间的啮合实现减速增矩。主要由三个部分组成：
1. 太阳轮（Sun Gear）：中间的小齿轮，通常连接电机输入轴。
2. 行星轮（Planet Gears）：围绕太阳轮分布的小齿轮，既自转又绕太阳轮公转。
3. 齿圈（Ring Gear）：外侧具有内齿的大齿轮。
### 磁粉制动器
磁粉制动器是一种利用电磁场控制磁性粉末之间的结合力，从而产生可调节制动转矩的装置。

## 编码器测速原理
一、编码器测速原理
面试标准回答：
我们的 ZqFOC 工程使用 AB 相增量式编码器，通过 STM32 的 TIM3 编码器模式进行四倍频计数，每圈对应4096个计数。
测速采用 M法（定时计数法），即每隔固定时间读取一次编码器计数值，计算相邻两次的计数差，再换算为转速。
计算公式：
\[
\boxed{n=\frac{\Delta N}{4096}\times\frac{60}{T}}
\]

其中：
- \(\Delta N\)：两次采样之间的编码器计数差。
- \(T\)：采样周期，单位秒。
- \(n\)：电机转速，单位rpm。
我们的速度环每1ms更新一次，因此 \(T=0.001s\)。
此外，程序还处理了编码器计数器的回绕问题，并通过计数差的正负判断电机旋转方向。
二、速度滤波原理
面试标准回答：
由于编码器测速采用离散计数，在低转速时容易出现量化误差和速度波动，因此我们采用一阶低通滤波对原始速度进行平滑处理。
计算公式：
\[
\boxed{v_k=v_{k-1}+\alpha(v_{\mathrm{raw}}-v_{k-1})}
\]

其中：
\[
\boxed{\alpha=\frac{T}{\tau+T}}
\]

- \(v_{\mathrm{raw}}\)：当前计算的原始速度。
- \(v_{k-1}\)：上一次滤波后的速度。
- \(\tau\)：滤波时间常数。
- \(T\)：采样周期。
我们的工程设置：
\[
T=1ms,\qquad \tau=5ms
\]

所以：
\[
\alpha=\frac{1}{5+1}=\frac16\approx0.167
\]

也就是说，每次滤波后的速度由约16.7%的当前测量值和83.3%的上一次滤波结果组成。
这样可以减小编码器测速波动，使速度环反馈更加平滑，但也会引入一定的响应延迟。
## 无感FOC
### 滑模观测器
滑模观测器（Sliding Mode Observer，SMO）是一种基于系统数学模型的状态估计方法。它利用系统的已知输入和可测量输出，通过引入与估计误差有关的切换修正项，使估计误差趋向并保持在预先设计的滑模面上，从而估计系统中无法直接测量的状态或未知扰动。
#### 例子
假设我们要估算电机的反电动势。
根据电机电压方程：
\[
\boxed{u=Ri+L\frac{di}{dt}+e}
\]

其中：
- \(u\)：施加的电压（已知）
- \(i\)：测量的电流（已知）
- \(R,L\)：电机电阻、电感（已知参数）
- \(e\)：反电动势（需要估算）
1. 第一步：建立虚拟电机
SMO 根据已知电压和电机参数，预测电流 \(\hat i\)。
但最开始不知道反电动势，所以预测电流与实际电流可能不同。
2. 第二步：计算误差
\[
\boxed{s=\hat i-i}
\]
例如：
- 实际电流：2 A
- 预测电流：3 A
- 预测误差：+1 A
说明虚拟电机预测的电流偏大。
第三步：利用滑模控制修正预测
在虚拟电机的方程中加入修正项 \(z\)：
\[
L\frac{d\hat i}{dt}=u-R\hat i-z
\]

典型的滑模修正项为：
\[
\boxed{z=K\operatorname{sign}(s)}
\]

其作用是：
- \(\hat i>i\)：增加正向修正，压低预测电流。
- \(\hat i<i\)：施加反向修正，提高预测电流。
这种根据误差正负切换修正方向的方式，就是滑模观测器的核心特征之一。
当误差到达滑模面：
\[
\boxed{s=\hat i-i=0}
\]

理想情况下，维持电流误差为零所需要的等效修正量就满足：
\[
\boxed{z_{\mathrm{eq}}=e}
\]

所以，SMO 能够通过修正项估算反电动势。
实际算法通常需要滤波，并使用饱和函数等方法减小高频抖振。
三、为什么叫“滑模”？
- 滑：系统误差到达指定的滑模面后，沿着它运动。
- 模：指系统的一种特殊运动模式。
- 观测器：指利用可测信号来估计无法直接测量的量。
在刚才的例子中，滑模面就是：
\[
s=\hat i-i=0
\]

我们的目的就是让预测误差到达并维持在零附近。
四、在无感 FOC 中有什么用？
对于 PMSM，SMO 在 \(\alpha\beta\) 两个轴上分别估算电流，通过滑模修正项重构反电动势：
\[
\boxed{
\begin{aligned}
\hat e_\alpha&\approx z_{\alpha,\mathrm{eq}}\\
\hat e_\beta&\approx z_{\beta,\mathrm{eq}}
\end{aligned}
}
\]

然后：
\[
\underbrace{\hat e_\alpha,\hat e_\beta}_{\text{反电动势}}
\xrightarrow{\text{相位估算/PLL}}
\underbrace{\hat\theta_e,\hat\omega_e}_{\text{角度和速度}}
\xrightarrow{\text{反馈}}
\text{FOC控制器}
\]

一句话总结：滑模观测器通过不断修正虚拟系统，使其预测结果跟踪真实系统；维持这种跟踪所需的等效修正量，可以帮助我们估算反电动势，进而实现无感 FOC。
因为反电动势 \(e\) 无法直接测量，而电流 \(i\) 可以直接测量。所以 SMO 采用一种间接估算的方法：
先预测电流，再利用预测电流与实际电流的误差，反推出未知的反电动势。
1. 为什么预测电流？
真实电机满足：
\[
L\frac{di}{dt}=u-Ri-e
\]

其中 \(u、i、R、L\) 已知，只有 \(e\) 未知。
我们建立一个虚拟电机：
\[
L\frac{d\hat i}{dt}=u-R\hat i-z
\]

这里的 \(z\) 是我们人为设计的修正项，用来代替未知的 \(e\)。
2. 怎么得到反电动势？
假设某个时刻：
- 实际电流 \(i=2\,A\)
- 预测电流 \(\hat i=3\,A\)
说明预测值偏高，SMO 就根据误差调整 \(z\)，使预测电流下降。
经过不断修正，预测电流逐渐跟踪实际电流：
\[
\hat i\rightarrow i
\]

这时比较两个方程：
\[
\begin{aligned}
L\frac{di}{dt}&=u-Ri-e\\
L\frac{d\hat i}{dt}&=u-R\hat i-z
\end{aligned}
\]

在理想滑模状态下，两者电流及其变化率一致，因此：
\[
\boxed{z_{\mathrm{eq}}=e}
\]

注意这里的 \(z_{\mathrm{eq}}\) 是滑模修正项的等效值，不是某一时刻的瞬时切换值。实际中通常需要滤波才能提取。
### 有了反电动势，怎么得到角度和速度？
第一步：根据反电动势计算转子电角度
对于表贴式永磁同步电机（SPMSM）：
\[
\begin{cases}
e_\alpha=-\omega_e\psi_f\sin\theta_e\\
e_\beta=\omega_e\psi_f\cos\theta_e
\end{cases}
\]
这里有一个关键关系：反电动势矢量与转子永磁体磁链方向垂直，相差90°电角度。
因此，在电机正转时：
\[
\boxed{\hat\theta_e=\operatorname{atan2}(-\hat e_\alpha,\hat e_\beta)}
\]

例如，SMO 估算得到：
\[
\hat e_\alpha=-5,\qquad\hat e_\beta=5
\]

那么：
\[
\hat\theta_e=\operatorname{atan2}(5,5)=45^\circ
\]

我们就得到了转子的估算电角度。
注意：反转时需要修正 \(180^\circ\) 的方向差异。
第二步：根据电角度得到电角速度
电角速度就是电角度对时间的变化率：
\[
\boxed{\hat\omega_e=\frac{\Delta\hat\theta_e}{T_s}}
\]

例如：
- 第一次计算：\(\hat\theta_e=0.5\,rad\)
- 1 ms 后：\(\hat\theta_e=0.6\,rad\)
那么：
\[
\hat\omega_e=\frac{0.6-0.5}{0.001}=100\ rad/s
\]

但实际中直接差分容易受到噪声影响，因此通常使用 PLL（锁相环）。
PLL 的原理非常简单：
1. 内部维护一个估算角度 \(\hat\theta_e\)。
2. 将这个角度与反电动势得到的角度比较。
3. 根据角度误差，通过 PI 调整估算电角速度 \(\hat\omega_e\)。
4. 将估算电角速度积分，更新估算角度。
最终 PLL 同时输出：
\[
\boxed{\hat\theta_e,\quad\hat\omega_e}
\]

第三步：转换为机械转速
电角速度和机械角速度之间存在极对数关系：
\[
\omega_e=p\omega_m
\]

所以机械转速为：
\[
\boxed{\hat n=\frac{60\hat\omega_e}{2\pi p}}
\]

其中 \(p\) 是电机极对数。
需要区分：这里估算的转子位置是电角度。若要获得机械角度，需要除以极对数；若要得到多圈绝对位置，还需要额外的初始位置和圈数信息。
### IF启动
### 1. 正常 FOC：定子磁场跟随转子

对于表贴式 PMSM，在 \\(i_d=0\\) 的控制方式下：

- 通过编码器或 SMO 获取转子电角度 \\(\theta_e\\)。
- 控制定子电流磁场，使其领先转子磁场约 90°电角度。
- 转子转动时，定子磁场同步转动，始终保持这一角度关系。
- 速度 PI 调整 \(i_q^*\)，决定输出转矩的大小。

因此，正常 FOC 中，定子电流磁场的方向跟随转子位置变化，而转矩大小由电流控制。

### 2. I/F 启动：定子磁场按照人为设定的频率旋转

I/F 启动时：

- 不知道转子的真实电角度。
- 人为生成 \(\theta\_{\mathrm{IF}}\)，控制定子电流磁场旋转。
- 转子受到磁场产生的电磁转矩作用，尝试跟随定子磁场。
- 两个磁场之间的夹角不再由控制器精确保持在 90°。

例如，假设 I/F 启动电流固定为 2 A：

| 两磁场夹角 | 相对最大转矩 |
| ----- | ------ |
| 30°   | 50%    |
| 60°   | 86.6%  |
| 90°   | 100%   |
| 120°  | 86.6%  |
| 180°  | 0%     |

这里采用理想表贴式 PMSM 的简化模型，转矩与两磁场夹角的正弦成正比。

因此，I/F 的目的是让转子能够跟随旋转磁场逐渐加速，而不是始终获得最大转矩。

### 3. 还有一个重要补充

I/F 中定子磁场与转子之间虽然没有直接的位置反馈联系，但两者仍然存在电磁耦合关系。

如果启动电流、加速度和负载合适，转子就能被牵引并逐渐与定子磁场同步旋转，此时：

\[ \boxed{\omega\_{\mathrm{rotor,e}}=\omega\_{\mathrm{IF}}} \]

但两者保持的相位差由负载和电机运行状态决定，不一定为 90°。

如果负载太大或人为加速太快，转子跟不上旋转磁场，就可能失步。

一句话总结：

- 普通 FOC： 根据转子位置控制定子磁场，主动维持合适的夹角，实现可控转矩。
- I/F 启动： 人为让定子磁场旋转，依靠电磁转矩牵引转子跟随，不保证最佳夹角，也不保证一定能够同步。

所以，你说的“只是能让它转起来”非常接近 I/F 启动的设计目的。更准确地说，是以适当的电流和频率斜坡，让转子稳定加速，为后续 SMO 无感闭环创造条件。
## SVPWM 的零序注入法和扇区判断法
SVPWM的目的是将目标电压矢量转换成三相PWM占空比，控制逆变器输出。
### 方法一：零序注入法（我们工程使用）
首先根据目标电压 \(V_\alpha,V_\beta\)，通过逆Clarke变换计算三相参考电压：
\[
\begin{aligned}
V_u &= V_\alpha\\
V_v &= -\frac12V_\alpha+\frac{\sqrt3}{2}V_\beta\\
V_w &= -\frac12V_\alpha-\frac{\sqrt3}{2}V_\beta
\end{aligned}
\]

然后计算公共零序电压：
\[
\boxed{V_0=-\frac{V_{\max}+V_{\min}}{2}}
\]

将零序电压同时叠加到三相参考电压，再计算PWM占空比：
\[
\boxed{D_u=0.5+\frac{V_u+V_0}{V_{dc}}}
\]

另外两相同理。
为什么要注入零序电压？
因为三相同时增加相同的电压偏置，不会改变相间电压，却能使三相参考电压更合理地分布在直流母线允许的范围内，从而提高母线电压利用率。
### 方法二：扇区判断法（传统SVPWM）
SVPWM 六个60°扇区示意图（S1～S6）
传统SVPWM将电压矢量平面划分为6个扇区，每个扇区60°。
主要流程：
1. 根据 \(V_\alpha,V_\beta\) 判断目标电压矢量位于哪个扇区。
2. 选择该扇区相邻的两个有效电压矢量。
3. 计算两个有效矢量和零矢量的作用时间 \(T_1,T_2,T_0\)。
4. 根据作用时间生成三相PWM占空比。
两种方法的区别： 扇区判断法显式计算扇区和矢量作用时间；零序注入法直接计算三相占空比。在相同的线性调制和开关序列条件下，两者可以实现等效的SVPWM调制效果。
我们的 foc_svpwm.c 使用的是零序注入法，不需要显式判断扇区。
#### 扇区判断如何计算占空时间
一、扇区判断法如何计算占空时间？
传统 SVPWM 的核心思想是：利用两个相邻的有效电压矢量和零矢量，在一个 PWM 周期内合成目标电压矢量。
第一步：判断扇区
经过逆 Park 变换得到：
\[
V_\alpha,\quad V_\beta
\]

计算目标电压矢量的角度：
\[
\theta=\operatorname{atan2}(V_\beta,V_\alpha)
\]

将角度归一化到0°～360°，每60°划分一个扇区。
例如，目标电压矢量为30°，就位于第一扇区。
第二步：计算两个有效矢量的作用时间
假设目标电压矢量位于第一扇区。
相邻两个有效矢量分别为：
- \(V_1\)：方向0°，开关状态100。
- \(V_2\)：方向60°，开关状态110。
设目标电压矢量幅值为 \(V_{ref}\)，它与扇区起始边界的夹角为 \(\alpha\)。
根据伏秒平衡原理：
\[
\boxed{
T_1=\frac{\sqrt3 V_{ref}}{V_{dc}}T_s\sin(60^\circ-\alpha)
}
\]

\[
\boxed{
T_2=\frac{\sqrt3 V_{ref}}{V_{dc}}T_s\sin\alpha
}
\]

零矢量的作用时间：
\[
\boxed{T_0=T_s-T_1-T_2}
\]

其中：
- \(T_s\)：一个PWM周期。
- \(V_{dc}\)：直流母线电压。
- \(T_1,T_2\)：两个有效矢量的作用时间。
- \(T_0\)：零矢量总作用时间。
这些公式适用于理想两电平三相逆变器的线性调制区域。
第三步：计算三相 PWM 占空比
以第一扇区、对称七段式 SVPWM 为例：
\[
\begin{aligned}
D_A&=\frac{T_1+T_2+T_0/2}{T_s}\\
D_B&=\frac{T_2+T_0/2}{T_s}\\
D_C&=\frac{T_0/2}{T_s}
\end{aligned}
\]

最后将占空比转换为 TIM1 的 CCR 比较值，生成三相 PWM。
其他扇区根据对应的有效矢量和开关顺序计算占空比。

### 注
对于SVPWM，扇区判断法只需要将PI输出的uq，ud通过反Park变为ualphabeta即可，而零序注入法需要将其进行反park 反clarke变换为uabc才行
## I2C通信
I2C 是一种同步、半双工、双线串行通信协议，主要用于 MCU 与传感器、EEPROM 等外设之间的短距离通信。
I2C 使用两根信号线：
- SCL（时钟线）：由主机提供时钟信号，用于同步数据传输。
- SDA（数据线）：用于双向传输数据。
通信流程：
1. 起始信号：SCL保持高电平时，SDA由高变低，表示通信开始。
2. 设备寻址：主机发送通常为7位的从机地址和1位读写控制位。
3. 应答信号（ACK）：接收方在第9个时钟周期拉低SDA，表示成功接收。
4. 数据传输：以8位为一组传输数据，每传输一个字节后进行一次ACK/NACK应答。
5. 停止信号：SCL保持高电平时，SDA由低变高，表示通信结束。
I2C的特点： 只需要两根信号线，可以通过不同地址连接多个从设备；SDA和SCL通常采用开漏输出，需要上拉电阻。
结合我们的项目： ESP32-S3 上位机通过 I2C 与 XL9555 GPIO 扩展芯片通信，实现扩展引脚控制，包括LCD背光相关控制。
### 面试容易追问：I2C和UART有什么区别？
UART是异步通信，不需要时钟线，通常通过TX和RX实现全双工通信；I2C是同步通信，通过SCL提供时钟，利用设备地址区分多个从设备，同一数据线上不能同时双向传输。

### 三、转速参数与 KV 值

这部分是电机面试中的重点。

| 参数        | 数值               |
| --------- | ---------------- |
| KV值       | 220 rpm/V        |
| 额定转速      | 2600 rpm / 12V   |
| 反电动势常数 Ke | 0.0434 V/(rad/s) |

#### 1. 什么是 KV 值？

KV 表示理想近似下，电机每增加1V电压对应的空载转速增加量。

例如：

\[ KV=220\ \mathrm{rpm/V} \]

在12V下，理想空载转速约为：

\[ n_0=KV\times U=220\times12=2640rpm \]


#### 2. 什么是反电动势？

电机转子旋转时，永磁体磁场与定子绕组之间发生相对运动，使绕组产生感应电动势。

这个电动势称为反电动势。

通常可以表示为：

\[ \boxed{E=K_e\omega} \]

其中：

- \(E\)：反电动势。
- \(K_e\)：反电动势常数。
- \( \omega \)：机械角速度。

转速越高，反电动势通常越大。

因此，在母线电压一定的情况下，电机转速不可能无限增加。

按照表中采用的定义，KV=220rpm/V对应的Ke约为0.0434V/(rad/s)。实际应用还要注意反电动势采用相电压、线电压、峰值还是有效值的定义。

### 四、转矩、磁链与转动惯量

| 参数       | 数值           | 含义                 |
| -------- | ------------ | ------------------ |
| 转矩常数 Kt  | 0.0434 N·m/A | 电流与转矩的比例系数         |
| 磁链 Flux  | 0.0035 Wb    | 永磁体在电机绕组中产生的等效磁链参数 |
| 转子转动惯量 J | 3700 g·mm²   | 转子对角加速度的惯性         |
| 力矩       | 300 gf·cm    | 厂家给出的力矩数值，未明确测试工况  |

#### 1. 什么是转矩常数 Kt？

转矩常数反映了电流产生电磁转矩的能力。

在适当的电流定义及线性工作条件下：

\[ \boxed{T=K_t I} \]

例如，按照厂家给出的 Kt=0.0434 N·m/A，在对应定义下1A电流产生约：

\[ T=0.0434N\cdot m \]

转矩常数越大，相同电流能够产生的转矩越大。

对于我们采用的表贴式PMSM、Id=0的FOC控制，在常用的dq峰值电流约定下：

\[ \boxed{T_e=\frac32p\psi_f i_q} \]

这也解释了为什么我们的速度环最终输出的是 Iq_ref：通过控制q轴电流调节电磁转矩。

需要注意，厂家给出的Kt与这个公式中的Iq可能采用不同电流定义，不能未经换算就直接等同。

#### 2. 什么是磁链 Flux？

磁链反映磁场与绕组的耦合程度。
对于永磁同步电机，永磁体产生的磁链会影响：
- 反电动势大小。
- 电磁转矩的产生能力。
- 电机电压和速度之间的关系。
我们的电机磁链参数为：
\[ \psi_f=0.0035Wb \]
它通常用于PMSM数学建模、转矩计算以及模型前馈控制等。

### 3. 什么是转动惯量 J？
转动惯量表示物体对角速度变化的抵抗程度。
旋转运动中的基本动力学方程为：
\[ \boxed{J\frac{d\omega}{dt}=T_e-T_L-B\omega} \]
其中：
- \(J\)：转动惯量。
- \(T_e\)：电磁转矩。
- \(T_L\)：负载转矩。
- \(B\omega\)：黏性摩擦转矩。
我们的电机：
\[ J=3700\ \mathrm{g\cdot mm^2} =3.7\times10^{-6}\ \mathrm{kg\cdot m^2} \]

转动惯量越大，在相同净转矩下，电机加速和减速越慢。

这也是为什么速度环的响应通常比电流环慢。

表中的300 gf·cm约等于0.0294 N·m，但未说明是额定、峰值还是其他工况下的力矩，不能直接把它当成持续额定转矩。

## CAN通信
### 一、CAN通信原理

面试标准回答（约30秒）：

CAN是一种多主机、半双工、差分信号的串行通信总线，广泛应用于汽车电子和工业控制领域。它通过CAN_H和CAN_L两根差分信号线传输数据，具有抗干扰能力强、可靠性高的特点。

CAN采用基于消息ID的通信方式，通过ID标识报文，并利用硬件过滤器筛选需要接收的数据。

当多个节点同时发送数据时，CAN通过非破坏性位仲裁机制解决总线冲突，ID数值越小，优先级越高。

### 二、CAN通信的基本流程

以我们的 ZqFOC 项目为例：

1. 数据打包：ESP32-S3将控制指令和参数打包为8字节数据，并设置CAN ID为`0x100`。
2. 数据发送：通过TWAI控制器发送CAN报文，经CAN收发器转换成差分信号传输。
3. 数据接收：STM32G431通过FDCAN硬件过滤器筛选ID为`0x100`的报文，并存入接收FIFO。
4. 指令解析：主循环调用`FOC_CAN_ProcessRx()`读取FIFO中的报文，根据第一个字节判断指令类型，解析后面的参数。
5. 指令执行：调用对应控制函数，实现速度设置、位置设置、模式切换及电机启停。

STM32再通过`0x180`～`0x183`报文向ESP32反馈电机状态、位置、电流和速度。
在这个项目中，我使用 **CAN 总线实现 ESP32-S3 上位机与 STM32G431 电机控制器之间的双向通信**。

首先，在 ESP32 端，我使用 ESP-IDF 提供的 TWAI 驱动，通过配置结构体设置 CAN 的收发引脚、500kbps 通信速率以及发送队列等参数，完成 CAN 控制器初始化，并注册接收和发送完成回调函数。
**在命令发送方面**，我通过 LVGL 编写了控制界面，包括启停按钮、速度和位置滑块。当用户操作控件时，会触发对应的事件回调函数，将控制命令和参数打包成8字节的 CAN 数据帧，再调用 TWAI 驱动函数发送给 STM32。
**在 STM32 端**，我使用 FDCAN 外设接收数据，通过配置接收过滤器筛选指定 CAN ID 的报文，再从硬件 FIFO 中读取数据，根据命令编号执行电机启停、控制模式切换和目标值设置。
**在数据反馈方面**，STM32 会周期性地将电机转速、位置、dq轴电流以及运行状态打包成不同 CAN ID 的报文发送给 ESP32。ESP32 收到报文后，通过接收中断回调将数据放入 FreeRTOS 队列，再由 LVGL 的定时器任务从队列中读取数据，根据 CAN ID 解析对应的信息，最后更新界面上的数值。
通过这种方式，我实现了电机的远程控制和运行状态实时监测，同时将 CAN 中断接收与界面更新分离，避免在中断中执行复杂的 UI 操作。

### 三、CAN通信常见面试追问

1\. CAN为什么抗干扰能力强？

因为CAN采用差分信号传输，接收器主要检测CAN_H与CAN_L之间的电压差，共模干扰对两条信号线的影响可以相互抵消。

2\. CAN如何进行总线仲裁？

CAN采用显性位0和隐性位1进行逐位仲裁。当两个节点同时发送时，如果某个节点发送隐性位1，却检测到总线为显性位0，就退出本次仲裁。因此，标准数据帧中ID数值越小，优先级越高。

3\. CAN一帧最多传输多少字节？

- 经典CAN：数据区最多8字节。
- CAN FD：数据区最多64字节。

我们的工程使用经典CAN，8字节数据帧，波特率500kbit/s。

4\. CAN通信如何保证可靠性？

CAN具有CRC循环冗余校验、ACK应答、位监测、错误检测及自动重传等机制，可以识别传输错误并进行恢复。但应用层仍需根据需要设计超时检测和命令确认机制。

5\. CAN为什么需要120Ω终端电阻？

CAN总线两端通常各接一个120Ω终端电阻，用于阻抗匹配，减少高速信号传输时的反射。两个终端并联后，在断电且无其他并联通路影响时，CAN_H与CAN_L之间测得的电阻通常约为60Ω。

面试重点记忆：

CAN的五个关键词是：差分传输、多主机、ID仲裁、硬件过滤、错误检测。

结合项目重点掌握：`ESP32 TWAI发送 → CAN总线 → STM32 FDCAN过滤 → RX FIFO接收 → 主循环解析 → 电机控制函数执行`。

## ZqFOC 电机工作状态机

### 1. 什么是状态机？

**状态机（State Machine）** 是一种程序设计方法，通过定义不同的工作状态以及状态之间的切换条件，管理系统的运行流程。

在 ZqFOC 工程中，状态机主要负责：

- 电机启动与停止。
- 转子电角度对齐。
- 对齐完成后的释放等待。
- 启动 FOC 闭环控制。
- 异常情况下关闭电机输出。

状态机主要位于：

- `User/foc_manager.h`：定义电机状态和控制接口。
- `User/foc_manager.c`：实现状态切换和工作流程。

### 2. ZqFOC 的四种工作状态

在 `foc_manager.h` 中，通过枚举定义四种状态：

```c
typedef enum
{
    FOC_STATE_STOPPED = 0,
    FOC_STATE_ALIGNING,
    FOC_STATE_ALIGN_RELEASE,
    FOC_STATE_RUNNING
} FOC_Motor_State;
```

| 状态 | 含义 | 主要工作 |
|---|---|---|
| `FOC_STATE_STOPPED` | 停机状态 | 关闭 PWM 功率输出，清除控制目标 |
| `FOC_STATE_ALIGNING` | 转子对齐状态 | 施加固定电压，校准编码器电角度偏置 |
| `FOC_STATE_ALIGN_RELEASE` | 对齐释放状态 | 撤去对齐电压，等待转子稳定 |
| `FOC_STATE_RUNNING` | 正常运行状态 | 执行 FOC 闭环控制 |

### 3. 状态机的工作流程

正常启动流程：

```text
           上电初始化
               |
               v
       FOC_STATE_STOPPED
            停机状态
               |
        接收到启动命令
               |
               v
       FOC_STATE_ALIGNING
            转子对齐
               |
      施加1V电压，保持1000ms
      采集编码器角度并校准
               |
               v
     FOC_STATE_ALIGN_RELEASE
            对齐释放
               |
       撤去电压，等待800ms
               |
               v
       FOC_STATE_RUNNING
            正常运行
               |
       执行FOC闭环控制
               |
        接收到停止命令
               |
               v
       FOC_STATE_STOPPED
```

在启动和对齐过程中，如果检测到部分异常，程序也会调用 `FOC_Motor_Stop()` 返回停机状态。

### 4. 状态机的程序实现

#### 4.1 状态变量

状态变量保存在电机总控结构体中：

```c
typedef struct
{
    volatile FOC_Motor_State motor_state;

    FOC_ENCODER_HandleTypeDef encoder;
    FOC_CURRENT_HandleTypeDef current;
    FOC_BUS_VOLTAGE_HandleTypeDef bus_voltage;
    FOC_SVPWM_HandleTypeDef svpwm;

    FOC_LOOP_CUR_HandleTypeDef loop_cur;
    FOC_LOOP_SPD_HandleTypeDef loop_spd;
    FOC_LOOP_POS_HandleTypeDef loop_pos;

} FOC_Motor_HandleTypeDef;
```

其中：

```c
volatile FOC_Motor_State motor_state;
```

用于记录电机当前的工作状态。

`volatile` 告诉编译器，该变量可能被正常程序流程之外的执行上下文访问或修改，避免对相关读取进行不恰当优化。

这里的状态变量由主循环相关函数修改，也会被中断服务程序读取。

#### 4.2 状态判断

在 `FOC_Motor_ProcessAlignment()` 中使用 `switch-case` 判断状态：

```c
static void FOC_Motor_ProcessAlignment(void)
{
    switch (foc_motor.motor_state)
    {
        case FOC_STATE_ALIGNING:
            FOC_Motor_HandleAligning();
            break;

        case FOC_STATE_ALIGN_RELEASE:
            FOC_Motor_HandleAlignRelease();
            break;

        default:
            break;
    }
}
```

该函数主要处理两个对齐阶段，而不是负责所有状态的切换。

#### 4.3 启动函数

```c
void FOC_Motor_Start(void);
```

主要流程：

1. 检查当前是否处于 `STOPPED`。
2. 检查电流零点校准是否完成。
3. 检查母线电压是否有效。
4. 清零控制目标和 PI 内部状态。
5. 启动三相互补 PWM。
6. 检查 PWM 通道使能和主输出使能状态。
7. 施加固定对齐电压。
8. 将状态切换为 `ALIGNING`。

对齐电压：

```c
#define ENCODER_ALIGN_VOLTAGE 1.0f
```

#### 4.4 转子对齐

在 `FOC_Motor_HandleAligning()` 中：

1. 保持固定电压 1000 ms。
2. 读取编码器机械角度。
3. 采集多个机械角度样本。
4. 计算编码器电角度偏置。
5. 撤去对齐电压。
6. 切换至 `ALIGN_RELEASE`。

对齐时间：

```c
#define ENCODER_ALIGN_TIME_MS 1000U
```

**目的：确定编码器零点与转子实际电角度之间的偏差，保证后续 Park 变换使用正确的电角度。**

#### 4.5 对齐释放

在 `FOC_Motor_HandleAlignRelease()` 中：

1. 等待转子稳定 800 ms。
2. 更新编码器角度。
3. 清除测速历史和 PI 历史状态。
4. 将位置目标设置为当前机械角度。
5. 启动 ADC 注入采样与 TIM6 中断。
6. 在速度模式下设置启动速度目标。
7. 切换至 `RUNNING`。

释放时间：

```c
#define ENCODER_ALIGN_RELEASE_TIME_MS 800U
```

#### 4.6 停止函数

```c
void FOC_Motor_Stop(void);
```

主要执行：

1. 将电机状态设置为 `STOPPED`。
2. 关闭 TIM1 主输出 MOE。
3. 停止三相 PWM 和互补 PWM 输出。
4. 停止 ADC 注入采样触发链和 TIM6 中断。
5. 将速度、电流参考值清零。
6. 清除各个 PI 控制器内部状态。
7. 同步编码器角度和测速历史。
8. 将 SVPWM 目标电压设置为零。

**目的：安全关闭电机，并避免下一次启动时沿用之前的控制状态。**

### 5. 状态机与 FOC 控制算法的关系

状态机与 FOC 控制算法属于两个不同层次：

- **状态机**：管理电机的启动、对齐、运行和停止。
- **FOC 算法**：在电机运行时执行电流、速度和位置闭环控制。

只有处于 `FOC_STATE_RUNNING` 时，才正常执行闭环控制。

| 控制模块 | 执行频率 | 触发方式 |
|---|---|---|
| 电流环 | 16 kHz | ADC1 注入转换完成中断 |
| 速度环 | 1 kHz | TIM6 定时器中断 |
| 位置环 | 200 Hz | TIM6 中断计数分频 |

在 `ALIGNING` 阶段，PWM 已经启动，但不执行正常的闭环电流 PI，而是输出固定的对齐电压。

### 6. 主循环如何推进状态机？

在 `main.c` 中：

```c
while (1)
{
    FOC_CAN_ProcessRx();
    FOC_Motor_Task();
    FOC_CAN_SendFeedback();
}
```

其中：

```c
void FOC_Motor_Task(void)
{
    FOC_Motor_UpdateBusVoltage();
    FOC_KEY_Task();
    FOC_Motor_ProcessAlignment();
    FOC_VOFA_ProcessTx();
    FOC_VOFA_ProcessRx();
}
```

程序通过不断调用 `FOC_Motor_Task()` 检查当前状态及其切换条件。

使用 `HAL_GetTick()` 判断经过的时间，不需要在对齐流程中使用长时间阻塞延时。

这种方式称为**非阻塞状态机**。

其优点是：电机等待对齐或释放时，主循环仍然可以处理通信、按键和其他任务。

### 7. 总结

ZqFOC 采用四状态工作状态机：

\[
\boxed{
STOPPED
\rightarrow
ALIGNING
\rightarrow
ALIGN\_RELEASE
\rightarrow
RUNNING
}
\]

核心特点：

1. 通过枚举定义电机工作状态。
2. 使用 `motor_state` 保存当前状态。
3. 使用 `switch-case` 处理对齐阶段。
4. 采用非阻塞方式推进状态切换。
5. 将电机流程管理与 FOC 控制算法分离。
6. 在正常运行状态下，通过中断周期执行电流环、速度环和位置环。

当前工程尚未单独定义 `FAULT` 故障状态，部分异常通过 `FOC_Motor_Stop()` 直接返回 `STOPPED`。

**一句话总结：状态机负责决定电机当前应该做什么，FOC 算法负责决定电机运行时应该如何控制。**
