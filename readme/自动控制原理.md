2. 常见拉普拉斯变换

单位冲激 \(\delta(t)\)	\(1\)

微分性质：
\[
\mathcal{L}\left[\frac{dy}{dt}\right]=sY(s)-y(0^-)
\]

积分性质（积分下限为0，采用零积分初值）：
\[
\mathcal{L}\left[\int_0^t y(\tau)d\tau\right]=\frac{Y(s)}{s}
\]

二阶系统的五个动态性能指标
① 上升时间 \(t_r\)

输出第一次达到稳态值所需的时间（这里采用0%～100%定义）。

② 峰值时间 \(t_p\)

输出第一次达到最大峰值的时间。
\[
\boxed{t_p=\frac{\pi}{\omega_n\sqrt{1-\zeta^2}}}
\]

③ 超调量 \(M_p\)

最大峰值超过稳态值的百分比：
\[
\boxed{M_p=e^{-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}}\times100\%}
\]

注意：对于标准欠阻尼二阶系统，超调量只与阻尼比有关。

④ 调节时间 \(t_s\)

系统响应进入并保持在稳态值附近允许误差带内所需的时间。

按2%误差带，常用近似公式：
\[
\boxed{t_s\approx\frac{4}{\zeta\omega_n}}
\]

按5%误差带：
\[
t_s\approx\frac{3}{\zeta\omega_n}
\]

这些是常用包络近似，不是所有阻尼比下的精确值。

⑤ 稳态误差 \(e_{ss}\)
\[
e_{ss}=\lim_{t\to\infty}e(t)
\]

反映系统稳定后的跟踪精度。

## 根轨迹
1. 所谓根轨迹，就是闭环特征根随着开环增益 \(K\) 的变化而形成的运动轨迹。对于连续系统，闭环系统渐近稳定的充要条件是所有闭环特征根都位于左半平面，即：
\[
\operatorname{Re}(s_i)<0
\]

2. 所有根轨迹都起始于开环极点，终止于开环零点或无穷远处。根轨迹的分支数等于开环极点的个数。

3. 绘制根轨迹需要确定以下内容：

1. 实轴上的根轨迹：实轴上某一点右侧的开环实零极点总数为奇数，则该点位于正增益根轨迹上。

2. 渐近线：当开环极点数 \(n\) 大于开环零点数 \(m\) 时，存在 \(n-m\) 条渐近线。需要计算渐近线与实轴的交点以及渐近线角度。

      渐近线与实轴的交点：
\[
\boxed{\sigma_a=\frac{\sum p_i-\sum z_i}{n-m}}
\]

      渐近线角度：
\[
\boxed{\theta_k=\frac{(2k+1)180^\circ}{n-m}}
\]

其中 \(k=0,1,\ldots,n-m-1\)。

3. 分离点：两条或多条根轨迹在实轴上汇合并离开实轴的位置。由闭环特征方程求出 \(K=f(s)\)，然后令：
\[
\boxed{\frac{dK}{ds}=0}
\]

      求出候选点，再判断是否位于正增益根轨迹上。

4. 虚轴交点：令 \(s=j\omega\)，代入闭环特征方程，分别令实部和虚部等于零，求出对应的增益 \(K\) 和频率 \(\omega\)。
- 临界增益 \(K\)：表示闭环极点到达虚轴时的增益，通常用于确定系统的稳定范围。
- 交点频率 \(\omega\)：当交点为非零纯虚极点时，表示系统在稳定边界处的振荡角频率。
      对应的振荡周期为：
\[
\boxed{T=\frac{2\pi}{|\omega|}}
\]

5. 稳定范围：根据根轨迹与虚轴的交点，结合劳斯判据，确定使所有闭环极点位于左半平面的 \(K\) 值范围。

4. 最后，根据开环零极点、实轴根轨迹、渐近线、分离点和虚轴交点绘制完整根轨迹。根轨迹关于实轴对称，并用箭头标明增益 \(K\) 增大的方向。

总结：根轨迹就是利用开环零极点，研究闭环极点随着增益变化的运动规律，从而判断闭环系统的稳定性和动态性能。
