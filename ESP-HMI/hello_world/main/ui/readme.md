# LVGL 速度与位置页面

`Ui_speed.c/.h` 是原 `motor_ui.c/.h` 的速度页面；`Ui_position.c/.h` 按相同风格实现单圈位置页面。`main.c` 在 LVGL 锁内先调用 `UI_Position_Create(display)`，再调用 `UI_Speed_Create(display)`，默认显示速度页面。

- 页脚 POSITION / SPEED 按钮只切换显示，不发送电机模式命令。
- 释放滑块：先发送 SET_MODE，再发送当前页面的目标。
- START：按顺序发送模式、目标、启动。STM32 对齐完成后应用缓存目标。
- STOP：两个页面都发送同一个停机命令。
- 速度页的 50 ms 定时器读取 CAN 队列，更新两页；位置页不另建任务或定时器。1 秒没有有效反馈时显示 OFFLINE。

## CAN 数据格式

全部使用标准 ID、Classic CAN、500 kbps、8 字节数据帧，多字节参数按小端排列。

| ID | Byte0 | Byte1～2 / 其余数据 |
|---|---|---|
| 0x100 | 命令：01模式、02速度、03位置、04启动、05停止 | Byte1/2为参数，Byte3～7为0；模式0速度/1位置，速度int16 rpm，位置uint16角度×100 |
| 0x180 | 电机状态 | Byte1为控制模式，Byte2～7为0 |
| 0x181 | Byte0/1：实际角度 | Byte2/3：目标角度，均为uint16角度×100；Byte4～7为0 |
| 0x182 | Byte0/1：Iq_ref | Byte2/3：Iq，Byte4/5：Id_ref，Byte6/7：Id，均为int16电流×100 |
| 0x183 | Byte0/1：实际速度 | Byte2/3：目标速度，均为int16 rpm；Byte4～7为0 |

位置范围是 `0～359.99°`，例如90°参数9000，Byte1/2为 `28 23`；359.99°参数35999，Byte1/2为 `9F 8C`，不能按有符号int16解析。单圈角度采用最短路径，零点来自编码器上电计数，不是机械回零。

位置页顶部表示用户滑块目标，下方 Ref / Actual 表示 STM32 反馈的目标与实际位置。切到速度页后按下 START 或释放滑块才会切换回速度模式。

STM32 每25ms轮流提交状态、位置、电流、速度，各类正常周期100ms；发送FIFO满时跳过，不阻塞FOC主循环。提交成功不等于总线已成功发送。速度模式的位置反馈仍用于观察转子机械角。

串口角度设置及波形通道见 [VOFA+ 使用指南](../../../../readme/03_串口通信与VOFA使用指南.md)。
